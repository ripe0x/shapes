- Contracts (`src/`): adopted v2 architecture on main. Shapes core (sole ETH custodian) + ShapeRenderer + ShapeLens (EIP-170 spillover periphery) + ShapeCollection + ShapeAuctionHouse/ShapeCardEscrow. The gas-ceiling suite measures every value-moving entrypoint and the exact 10k ladder tree. Medusa 1.5.1 passes 10/10 reserve/lifecycle tests (34,350 calls in the Director rerun); its oversized harness is isolated from production size builds. Preview has 47 passing tests; TypeScript, renderer verification/sweep/fixtures/parity, web lint/build, indexer zero-audit/codegen/typecheck/Anvil smoke, shell syntax, docs, local Anvil e2e and both size gates pass. Coverage remains ~96.75% line / 90.95% branch per the last x-ray run.
- Site (`web/`): Next.js 16.3.3 on Netlify (git auto-deploy from main). It imports all UI/chain logic from `preview/src` via `@shared`. Browser and OG clients share optional-primary plus independent public RPC fallbacks. Black Shapes remain visible with canonical art and no invalid mutators; provenance rollups render as counts. WalletConnect is enabled only when a real public project id is supplied; injected wallets remain available without one. - Preview (`preview/`): canonical TS renderer + parity/fixture/sweep/simulation tooling. `preview/scripts/inkTuning.ts` exists (ink-gene tuning harness).
- Indexer (`indexer/`): Ponder 0.17.8, self-contained, builds token + lineage-edge state including compose depth and recipient-correct split/decompose ownership. It is integrated but not hosted; activation needs the fresh Shapes address/start block, an archive Sepolia RPC and explicit authorization for Railway/Postgres resources.
