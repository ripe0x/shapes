# Experiment record

One file per experiment under project/experiments/, named EXP-NNN-slug.md. Referenced from the decision it resolves.

- Id / date / decision served: (e.g. EXP-001, D-08)
- Hypothesis: the claim being tested, falsifiable
- Method: exact commands, seeds, block pins, tool versions; reproducible by a stranger
- Results: raw numbers or artifact paths; no summarizing away the data
- Conclusion: hypothesis supported / refuted / inconclusive
- Decision impact: what this closes or changes in DECISIONS.md
- Follow-ups: new questions raised
