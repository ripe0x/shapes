# EXP-004 — Renderer module-helper refactor

- Id / date / decision served: EXP-004, 2026-08-31, D-32 / GitHub issue #7
- Hypothesis: extracting `ShapeRenderer._moduleSvg` into private per-kind helpers can lower its normalized cyclomatic complexity without changing any generated bytes, public interface, storage, runtime-size baseline, or materially increasing gas.
- Baseline: exact `main` commit `e679da05`, Forge 1.8.1, solc 0.8.28, Slither 0.11.5. ShapeRenderer runtime size was 23,185 bytes under the default profile and 23,184 bytes under `testnet`.
- Method:

  ```sh
  forge test --match-contract RendererGasTest -vv
  forge test -vv
  FOUNDRY_PROFILE=testnet forge test -vv
  forge build --sizes
  FOUNDRY_PROFILE=testnet forge build --sizes
  slither src/ShapeRenderer.sol --print function-summary

  cd preview
  npx tsc --noEmit
  npm run verify
  npm run sweep
  npm run fixtures
  SHAPES_LADDER=testnet npm run fixtures
  git diff --exit-code -- ../test/fixtures/fixtures.mainnet.json ../test/fixtures/fixtures.testnet.json
  npm test
  ```

  `RendererGasTest` pins seed-derived and sampled SVG, metadata, and tokenURI calls at the one- and 25-module extremes. Slither's early-return CFG undercounts the dispatch and helpers, so complexity is normalized using D-32's standard `1 + control-flow decision points` method.

## Results

The refactor produces byte-identical output against both the unchanged TypeScript fixture corpus and the frozen pre-refactor Solidity renderer. `RendererDiffTest` covers seed and sampled paths, all denomination/gene/inversion combinations, every valid module byte, malformed module bytes, metadata, tokenURI, SVG, Unicode, and glyph surfaces.

| profile | runtime before | runtime after | change | EIP-170 margin after |

| default | 23,185 B | 23,138 B | -47 B | 1,438 B |
| testnet | 23,184 B | 23,137 B | -47 B | 1,439 B |

Worst observed gas regression is 0.0104%, well below D-32's 5% review threshold. One-module probes improve by 18–24 gas; 25-module probes increase by 2 gas on seed paths and 115 gas on sampled paths.

Normalized complexity falls from 16 for the monolithic `_moduleSvg` to 10 for dispatch. The helpers score 1–3: `_diamondSvg` is 3; `_triangleSvg`, `_quarterSvg`, `_rightTriangleSvg`, and `_halfCircleSvg` are 2; the remaining helpers are 1. Every extracted helper is below the acceptance ceiling of 11. `_glyph` is unchanged as the documented cohesive lookup-table exception.

Both Foundry profiles pass 453 tests with 4 expected fork-only skips. The preview typecheck, stream verification, 4,500-card collision sweep, both fixture regenerations, fixture no-diff check, and all 115 preview tests pass.

- Conclusion: hypothesis supported. The behavior-only extraction satisfies every D-32 gate, reduces runtime size by 47 bytes in both profiles, and keeps gas effectively flat.
- Decision impact: close issue #7 after normal PR review and CI. The renderer is ready to enter the D-16 external-audit snapshot; no renderer module, vocabulary, grammar, ABI, storage, metadata, or geometry expansion is authorized by this result.
